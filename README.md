## 🚀 About The Project

**Wireish** is a cutting-edge SaaS platform designed to deliver enterprise-grade AI automation solutions. Our architecture seamlessly connects smart AI agents with modern customer touchpoints (Web widgets, Instagram Direct, and WhatsApp Business API) to maximize conversion and streamline client support.

---

## ✨ Key Features

* **Pill-Shaped Dynamic Navbar**: Smooth scroll-triggered layout transitions powered by Framer Motion and inline precision styling.
* **Interactive ROI Calculator**: Custom dynamic pricing module allowing clients to calculate tailored estimates instead of static tiers.
* **Multi-Channel AI Integration**: Automated agents built for Web, IG, and WhatsApp ecosystems.
* **Bulletproof Legal Infrastructure**: Comprehensive, enterprise-level *Privacy Policy* and *Terms of Service* safeguarding operational liability.
* **Secure Preview Mode**: Built-in password-protected maintenance mode (*Site Under Construction*) for team testing prior to public release.
* **Direct Lead Capture**: Integrated API routing via Resend for instant email notifications on demo bookings.

---

## 🛠️ Tech Stack

* **Framework**: [Next.js](https://nextjs.org/) (App Router)
* **Styling**: [Tailwind CSS](https://tailwindcss.com/)
* **Animations**: [Framer Motion](https://www.framer.com/motion/)
* **Icons**: [Lucide React](https://lucide.dev/)
* **Email Service**: [Resend](https://resend.com/)
